# ManutencaoSoftware-API-Django
API REST desenvolvida em Django para gerenciamento de Projetos e Tarefas. Este projeto foi desenvolvido para a disciplina de Manutenção de Software (UFERSA). A API suporta operações CRUD completas para tarefas, persistência em SQLite e inclui validações de regras de negócio, cobertura de testes unitários e análise de métricas de código.
